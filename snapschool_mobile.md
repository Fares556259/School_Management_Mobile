# SnapSchool Mobile Redesign Tracker

## Status
- **Overall UI Style:** Duolingo-inspired (thick 2px borders, bright white backgrounds, deep shadows, 900-weight typography).
- **Core Colors:**
  - Primary Brand: SnapSchool Blue (`#0072e6`, `#0055b3`)
  - Accent Green: `#16a34a` (Success/Paid/Present)
  - Accent Red: `#dc2626` (Error/Overdue/Absent)
  - Accent Orange: `#d97706` (Warning/Late/Partial)
  - Surface: `#ffffff` (Main), `#f8fafc` (Secondary)

## Screens Redesigned ✅
- **App/Tab Navigation:** Removed floating shadows; implemented thin, flat border-top tab bar.
- **SignInScreen:** Bright white auth, 3D animated buttons, bold CTAs.
- **LandingScreen:** Bolder typography, 2px borders on Role Cards, thicker drop shadows.
- **HomeScreen:** Dashboard converted to Duolingo blocks.
- **AnnouncementsScreen:** Flattened list with 2px borders, thick date tags.
- **CoursesScreen:** Grid converted to Duolingo standard.
- **PaymentsScreen:** 2px border cards, red borders for overdue, thick progress bars, 3D "Pay Now" CTA.
- **AttendanceScreen:** Huge 3D trend card, bold status pills, completely revamped layout.
- **NotificationsScreen:** Styles updated (2px borders on cards and tabs, colored active tabs, bold text).

## Upcoming / To-do 🚧
- **Teacher/Student Portals:** Expand the Duolingo design language to Teacher and Student-specific screens.
- **Exam / Grades Screen:** Redesign to match the new bold standards.
- **Profile / Settings Screen:** Modernize to fit the flat/bordered aesthetic.
